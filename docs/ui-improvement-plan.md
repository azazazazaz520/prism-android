# Prism Android UI 改进方案

> 基于当前 Vue 3 + Tauri 2 Android 项目的组件、领域能力和已有交互整理。
> 本文记录方案与验收标准；先完成浏览器原型，再根据验证结果实施 P0。原型和 UI 实施均不调整 Rust、数据库和同步数据模型。

## 1. 现状判断

当前项目已经具备任务创建、日期筛选、标签筛选、重要/置顶/每日重复、编辑、删除、离线保存和同步状态等能力。主要问题集中在信息层级和交互层级：

- 添加任务展开后同时显示过多选项，键盘打开时输入区和详情区争夺可视空间。
- 任务卡片同时提供完成、编辑、删除和左滑删除，右侧操作密度较高。
- 日期条和标签条连续占用两行，筛选条件不容易被快速识别和清除。
- 同步状态已有实现，但需要更明确地表达“已保存到本机”和“正在上传”的区别。
- 正文和辅助文本的字号偏小，部分图标按钮的视觉尺寸小于 Android 推荐的触控区域。

## 2. 设计方向

- 保留 Prism 的 Teal 品牌色和当前桌面端品牌图标。
- 采用轻量扁平、内容优先、触控优先的移动任务界面。
- 每个页面只保留一个主要动作：任务页主要动作是添加任务，设置页主要动作是完成同步配对。
- 通过间距、字号和表面层级建立信息层次，减少无意义的边框和重复按钮。
- 所有主要触控目标保持至少 48dp；图标按钮必须有可访问名称和明确的按压状态。
- 键盘、底部导航、系统安全区和详情面板使用同一套可视区域计算，避免固定偏移互相覆盖。

## 3. 分阶段计划

### 原型阶段：先验证界面结构

浏览器原型使用开发环境专用路径，不读取真实任务、不写入 localStorage、Rust 或 Supabase。它用于比较三种信息层级和新增任务入口：

- `focus`：推荐方案。标题与数量前置，日期和标签筛选收敛，底部快速输入展开为 Bottom Sheet。
- `agenda`：日期优先。以日期分组和时间线强化“今天要做什么”，适合日程感更强的使用方式。
- `canvas`：留白优先。保留较大的空状态和中心新增入口，验证轻量、低密度任务页是否更符合 Prism 的气质。

原型地址：`/prototype/tasks-ui?variant=focus`。底部切换器支持鼠标点击和键盘左右方向键，便于在三个变体之间比较。原型只保留交互答案，确认方向后删除落选变体，并将胜出结构重新实现到正式组件中。

原型阶段重点观察：

- 用户能否在不解释的情况下找到唯一的新增任务入口。
- 键盘打开时，标题、输入框、详情选项和保存按钮是否仍然可见。
- 日期筛选、标签筛选和任务列表之间的层级是否清晰。
- 空状态是否能引导第一次创建任务，而不是只表达“没有内容”。

### P0：核心操作闭环

#### P0-1 添加任务与键盘适配

- 收起状态只显示快速输入栏。
- 聚焦后输入栏固定在键盘上方，标题、光标和保存按钮始终可见。
- 日期、标签、重要、置顶、每日重复放入“更多设置”，采用渐进式展开。
- 详情区域只有一个滚动容器，保存操作保持可达。
- 使用可视视口、底部导航高度和安全区计算位置，移除脆弱的固定 `64px` 偏移。
- 关闭详情时保留标题草稿；提交成功后清空标题和元数据。

验收：在 320px、360px、412px 宽度，以及竖屏键盘打开状态下，输入框和保存按钮不被遮挡；详情内容可以滚动；任务元数据仍按现有接口保存。

#### P0-2 任务卡片层级

- 默认只展示完成按钮、任务标题和一个“更多”操作入口。
- 编辑和删除收进操作区，左滑删除继续作为快捷方式保留。
- 日期显示为“今天”“明天”或本地化日期；标签最多展示两个，超出显示数量提示。
- 重要、置顶和每日重复以简短元信息表达，不抢占标题空间。
- 完成任务降低对比度并保留可读性，不让整张卡片变得难以辨认。

#### P0-3 筛选区域整理

- 保留日期横条，但降低视觉重量。
- 标签默认收进“筛选”入口，只在需要时展开。
- 显示已选筛选条件和清除入口，避免用户忘记当前筛选状态。
- 统计数字基于当前筛选结果，空状态文案随日期和标签变化。

### P1：反馈与可读性

- 顶部持续显示同步状态、最近同步时间和离线提示。
- 添加加载骨架、同步失败重试、保存成功反馈和可恢复错误提示。
- 同步设置增加复制、分享、重新配对和使用步骤说明。
- 正文建议使用 16px，辅助文字不低于 13px；分别检查浅色和深色主题的对比度。
- 所有图标按钮补齐 48dp 点击区域、`aria-label`、焦点状态和按压反馈。

### P2：统一质感

- 统一图标线宽、圆角、阴影和动效节奏。
- 增强空状态和首次使用引导，但不增加复杂 onboarding。
- 支持系统字体放大和减少动画偏好。
- 在小屏、平板、横屏和深色模式下做一次完整视觉回归。

## 4. P0 实施范围

原型验证通过后，再进入正式 UI 实施。正式实现优先拆分新增任务 Sheet 和日期选择 Sheet，保留现有 `useTaskStore` 的任务创建、筛选、软删除和同步边界。

本轮修改以下文件：

- `src/components/TaskInput.vue`
- `src/components/TaskList.vue`
- `src/components/TagChipBar.vue`
- `src/views/TasksView.vue`
- `src/App.vue`
- `src/styles/tokens.css`
- `src/styles/global.css`

原型阶段只允许新增或修改以下开发专用文件：

- `src/prototype/TaskUiPrototype.vue`
- `src/router.ts`（仅在开发环境注册原型路由）
- 本方案文档

不修改任务数据结构、Rust 命令、Supabase 迁移和同步合并逻辑。

## 5. P0 验证清单

- `npm run test`
- `npm run build`
- `npm run format:check`
- 375px 小屏和横屏布局检查
- Android 键盘打开、关闭、切换输入法检查
- 任务标题、日期、标签、重要、置顶、每日重复组合创建检查
- 编辑、删除、左滑删除和筛选状态回归检查
- 深色/浅色主题和 `prefers-reduced-motion` 检查

## 6. 浏览器原型验收清单

- `/prototype/tasks-ui?variant=focus`、`agenda`、`canvas` 均可直接打开。
- 原型中的新增、日期选择、标签选择和取消操作只改变内存状态，刷新后恢复示例数据。
- 原型切换器只在开发环境显示，不进入生产页面。
- 三个变体具有不同的信息结构，而不是只更换颜色或文案。
- Sheet 有背景遮罩、明确的关闭路径和保存/取消动作。
- 日期选择面板显示取消与确认，确认前不改变草稿日期。
- 在 375px 宽度、横屏和键盘模拟缩小视口下不出现横向滚动。

## 7. 真机验证发现与补充建议（2026-08-21）

> 基于 HUAWEI Pura 70 Pro（1260×2844，density 540，Android 竖屏）实机截图验证。
> 已验证通过的部分：新增 Sheet 键盘适配（标题、保存按钮始终可见）、浅色/深色主题切换、同步状态、状态栏/导航栏安全区。以下为实机观察到的**新问题**与补充建议，按优先级排列。

### P0 首屏与核心交互（实机优先项）

- **首屏信息层级过重**：顶栏 → 头部（今天·日期+新增按钮）→ 进度卡 → 分段 Tab → "选择日期"区块 → "任务"区块共 5 个信息层，首屏只能看到 1~2 行任务。建议合并日期信息（头部一行："今天 · 8月21日 · 2 项待办"），进度卡压缩为进度条，日期区折叠或后置，让任务列表成为首屏主体。
- **新增按钮位置**：右上角"新增"单手拇指难以触达，建议改为底部导航中间 FAB（当前底部只有 2 个 Tab，中间有天然空位）。
- **任务操作层级**：完成/编辑/删除藏在 "⋯" 弹出菜单，建议增加左滑露出 完成/删除 的快捷操作（现有左滑删除可扩展），减少点按层级。
- **空状态较弱**：只有两行文字，建议加入简单 SVG 插画 + "添加第一个任务"主 CTA。

### P1 视觉与信息设计

- **日期信息重复**：头部"今天 · 8月21日"与"选择日期"区块重复表达同一信息，且日期条 7 个 chip 在 373dp 宽度几乎占满，小屏需横滑但无滚动提示（建议左右渐变遮罩）。
- **日期选中态区分度低**："今天"与"选中"都是 teal 描边，建议选中态用实心强调，今天用轻微描边。
- **进度数字重复**：进度卡"0/2 已完成"与头部"2 项待办"重复，可只保留一处。
- **设置页缺同步状态**：看不到是否已配对 profile、配对码、设备数，建议增加同步状态卡（已配对/未配对 + 操作入口）。
- **重要任务标识**：深色模式下任务卡左侧橙色竖条过于抢眼，建议改琥珀色或 "!" 徽标。

### P2 细节与功能

- 弹层"今天"按钮语义不明，建议改为显示当前值（如"8月21日"）并保留日历展开（现有日历体验良好）。
- "清除日期"文案建议改为"不限日期"。
- 功能建议：任务时间字段（当前仅日期）、周视图、提醒通知、标签管理（重命名/删除）。

### 实机已确认的正常项（回归基准）

- 冷启动后状态栏与顶栏文字无重叠（原生 getInsets 桥 + 前端拉取）。
- 键盘弹出时新增 Sheet 自动上移，标题与保存按钮不被遮挡。
- 底部导航不被手势条遮挡；深色模式下状态栏图标自动变白。
- 同步状态（已同步/同步中/离线）与离线队列计数显示正常。
